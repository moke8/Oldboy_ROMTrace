# 标准媒体操作图标设计

## 目标

将详情弹窗媒体操作的手绘图标替换为语义明确、跨平台一致的标准线框图标。

## 图标

- 上传：托盘与向上箭头组合，表示选择或替换当前媒体。
- 删除：带桶盖和内部竖线的完整垃圾桶轮廓，表示移除当前媒体。

两个图标使用项目内 20 像素 SVG，不引入第三方依赖。默认线条为浅灰色；禁用状态继续由 Qt 降低透明度；删除按钮的悬停边框保留红色提示。

## 实现

新增 `assets/icons/upload.svg` 和 `assets/icons/trash.svg`。媒体按钮直接通过资源路径构造 `QIcon`，删除 `create_media_action_icon()` 及其手绘线段逻辑。按钮尺寸、位置、对象名、工具提示、可访问名称和点击行为保持不变。

## 测试

- 两个 SVG 资源存在且包含可解析的 SVG 根元素。
- 上传和删除按钮图标均非空。
- 上传按钮工具提示明确为“选择或替换”。
- 删除按钮工具提示明确为“移除”。
- 原有 49 项测试继续通过。
