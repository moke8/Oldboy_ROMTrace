# DB Title Normalization Design

## Goal

Remove trailing parenthesized metadata from game titles generated by every
`build_*_db.py` script and apply the same cleanup directly to the existing
GBA, NDS, and PS1 database files.

## Normalization Rule

Repeatedly remove parenthesized groups from the end of a title, including the
whitespace immediately before each group. After all trailing groups have been
removed, remove any remaining trailing whitespace.

Examples:

- `Digimon - Battle Spirit (Europe) (En,Fr,De,Es,It)` becomes
  `Digimon - Battle Spirit`.
- `Pac-Pix (Europe) (En,Fr,De,Es,It) (Demo) (Kiosk)` becomes `Pac-Pix`.
- `Game Title (USA)   ` becomes `Game Title`.
- `Collection (aka Game (Best))` becomes `Collection`.
- `Memories (aka Edition))` becomes `Memories`, tolerating the extra closing
  parenthesis in the source data.
- Parenthesized text that is not at the end of a title remains unchanged.

All trailing groups are removed without classifying their contents or limiting
their nesting depth. This includes region, language, revision, disc, demo,
beta, kiosk, aliases, and other source metadata.

## Implementation

Add one shared title-normalization function for the database builders. The
GBA, NDS, and PS1 builders call it before storing a source title in their
serial mapping, so future generated databases contain normalized values.

Update `gba_game_db.py`, `nds_game_db.py`, and `ps1_game_db.py` in place with
the same transformation. Do not run any builder, download source data, change
mapping keys, or change the number of entries.

## Verification

Add focused unit tests for multiple trailing groups, trailing whitespace, a
title without metadata, and parenthesized text that is not trailing. Update
builder tests to verify extracted or emitted names are normalized. Verify the
three current databases are importable, retain their original keys and entry
counts, contain no values ending in a parenthesized group, and contain no
values with trailing whitespace.
