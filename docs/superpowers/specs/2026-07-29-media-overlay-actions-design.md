# 媒体框悬浮操作设计

## 目标

移除详情弹窗媒体框下方的三组“选择/移除”文字按钮，将操作收纳到各媒体页右下角的两个图标按钮，减少空间占用并明确操作对象。

## 交互

封面、Logo、视频三个标签始终显示。每个标签页右下角固定两个 28 像素图标按钮：

- 编辑图标：选择或替换当前标签对应的媒体。
- 删除图标：移除当前标签对应的媒体；当前没有媒体时禁用。

按钮默认使用低对比度深色半透明背景，悬停时提高亮度。删除按钮悬停时使用红色提示。两个按钮均提供中文工具提示和可访问名称。

封面与 Logo 没有内容时显示现有游戏占位图形，视频没有内容时显示视频占位提示。上传、替换、移除及保存行为保持不变。

## 实现

复用 Qt 绘制能力生成编辑和删除图标，不新增图片资源或第三方依赖。每个媒体标签页使用一个容器承载预览控件与右下角操作层；操作层只调用现有 `_choose_media(kind)` 和 `_remove_media(kind)`。

刷新媒体后重建三个标签页，并根据当前媒体状态更新删除按钮可用性。视频播放器的创建、停止和释放规则保持不变。

## 测试

- 始终显示封面、Logo、视频三个标签。
- 每页存在编辑与删除两个图标按钮，不再显示原文字按钮行。
- 无媒体时删除按钮禁用，有媒体时启用。
- 点击封面编辑按钮只触发封面选择。
- 点击视频删除按钮仍产生 `video_removed` 编辑状态。
- 原有媒体预览、编辑保存和视频播放测试继续通过。
